# References and reuse

## Why cite other work?

The references in the methods report situate the experiment. ACT motivates predicting short action sequences. The DAgger paper explains why errors accumulate when an imitation policy encounters states absent from demonstrations. Neither method is reproduced in full: the action head is an MLP, and DAgger is not implemented.

These references are not a claim of affiliation or endorsement. Maze data and display assets are generated by this repository's own code.

Open X-Embodiment provides context for learning action policies from diverse robot demonstrations. This project does not use its datasets or pretrained models. Links to the original papers and project pages are in the [methods report](METHODS.md).
